# Закрытый кабинет Line-Energy

Однопользовательская версия существующего конструктора. Авторизация проверяется
сервером для калькулятора, изображений и архива. Публичной регистрации нет.
Существующая локальная HTML-версия и Tilda работают отдельно.

## Локальный запуск

Требуется Node.js 24 LTS. Дополнительные пакеты не нужны.

```powershell
node Private/server.js
```

Сервер слушает только `127.0.0.1:8787`. При первом запуске в терминале выводится
одноразовая ссылка создания кабинета. Откройте её и самостоятельно задайте логин
и пароль от 12 символов. После создания аккаунта ссылка перестаёт работать.
В дальнейшем вход: `http://127.0.0.1:8787/login`.

В Windows база по умолчанию находится в `%LOCALAPPDATA%/LineEnergyCabinet`,
на Linux — `~/.local/share/line-energy-cabinet`. Это отдельная папка, вне
репозитория и OneDrive. Не помещайте её в синхронизируемые облачные папки.
Расположение можно изменить переменной `CABINET_DATA_DIR`.

После входа открывается архив КП. Создание, изменение, копирование, удаление,
экспорт и импорт используют прежний формат проекта. Сервер подтверждает сохранение
до появления сообщения об успехе. При одновременном редактировании в двух окнах
устаревшее сохранение отклоняется, а не перезаписывает новые данные.
Сеанс действует 12 часов. После истечения можно войти в другой вкладке и повторить
сохранение, не закрывая страницу с несохранённым расчётом.

## Перенос старых КП

1. Откройте прежний локальный `Web/index.html` в том браузере, где сохраняли КП.
2. В «Архиве КП» нажмите «Экспорт JSON».
3. Войдите в новый кабинет и нажмите «Импорт JSON».

Браузер не даёт серверу прочитать архив, сохранённый по адресу `file://`.
Поэтому перенос выполняется явно. Старый архив автоматически не удаляется.
Не добавляйте экспортированные JSON с данными клиентов в GitHub или облачные папки.

## Размещение в интернете

Для доступа с других устройств нужен отдельный сервер. Встроить серверную
авторизацию и базу данных внутрь HTML-блока Tilda нельзя. На Tilda можно оставить
ссылку на закрытый кабинет, например `cabinet.line-energy.ru`.

Перед размещением:

1. Создайте единственную учётную запись локально на сервере через SSH-туннель.
   До создания аккаунта не открывайте сервис наружу. После первичной настройки
   запускайте с `CABINET_ORIGIN=https://cabinet.line-energy.ru`.
2. Задайте `CABINET_DATA_DIR=/var/lib/line-energy-cabinet`, владельцем каталога
   должен быть отдельный непривилегированный пользователь сервиса.
3. Приложение оставьте на `127.0.0.1:8787`; наружу публикуйте только HTTPS через
   reverse proxy. Установите TLS-сертификат. Прокси должен передавать исходный
   заголовок `Host`, не добавлять CORS и не кешировать ответы.
4. Включите автозапуск службы, обновления ОС и ежедневные резервные копии базы.
   Доступ к копиям ограничьте тем же владельцем. Храните копии в РФ.
5. Импортируйте старые КП и проверьте открытие сохранённого проекта и выпуск PDF.

Пример блока nginx после установки сертификата:

```nginx
server {
    listen 443 ssl;
    server_name cabinet.line-energy.ru;
    ssl_certificate /path/to/fullchain.pem;
    ssl_certificate_key /path/to/privkey.pem;
    client_max_body_size 16m;
    location / {
        proxy_pass http://127.0.0.1:8787;
        proxy_set_header Host $http_host;
    }
}
```

Значение `CABINET_ORIGIN` должно точно совпадать с внешним HTTPS-адресом,
без завершающего `/`. В этом режиме cookie помечается `Secure`, проверяются
Host и Origin. Первый аккаунт через интернет создать нельзя.

Пароль хранится как scrypt-хеш со случайной солью; сеансы — в виде хешей токенов.
Ограничены попытки входа, срок сеанса и размер архива; изменения защищены CSRF-токеном.
Архив не хранится в localStorage кабинета. Пароли и клиентские проекты не входят
в код приложения. Эти технические меры не являются юридическим заключением
о соответствии 152-ФЗ: основания обработки, документы оператора, сроки хранения,
уведомление Роскомнадзора и условия с хостингом оформляются отдельно.

## Резервная копия

Остановите службу и скопируйте весь каталог данных, включая файлы SQLite WAL/SHM,
если они остались. Запустите службу обратно. Для восстановления остановите службу,
верните сохранённый каталог с теми же правами и запустите приложение.
Храните копию отдельно от рабочего диска; JSON-экспорт КП также остаётся доступным.
